# Cognitive Holobiont Research

Rigorous research dossier for the Cognitive Holobiont Treatise.

## Current milestone

Milestone 24 — Mechanism Identifiability, Memory Governance, and Non-Stationary Generalization Audit

The Treatise remains falsification-first. Major claims are classified as established, plausible engineering synthesis, unsupported/speculative, or mathematically incorrect/incomplete. No end-to-end validation is claimed.

### Milestone 24 findings

- Different MoE routing topologies can be empirically equifinal in some controlled settings; topology-level equifinality can coexist with expert-level causal specialization.
- Mechanism claims require interventions or identifiable invariants; benchmark improvement alone does not identify a cognitive mechanism.
- Structured, temporal, clustered, event-centric, procedural and latent memories show bounded benchmark gains, but memory improvement is not equivalent to truth or generalization.
- Self-evolving memory and skill systems change future data distributions, so before/after evaluation needs feedback and drift controls.
- Derived skills are persistent state: deleting a source memory does not necessarily roll back behavior.
- Non-stationary Byzantine learning requires tracking formulations such as dynamic regret when online assumptions apply.
- Nominal specialist count is not evidence count when checkpoints, data, encoders, memory or infrastructure are shared.
- Active-subgraph Byzantine concentration must be measured separately from global Byzantine fraction.
- Privacy and robustness should be evaluated jointly because privacy mechanisms can alter robustness evidence.

## Methodology

For each claim: define the proposition; type every mathematical object; identify primary evidence; compare conflicting findings; state assumptions; derive or correct equations; define a falsification experiment; specify statistical evaluation. Milestone 24 adds mechanism-identifiability, intervention-level MoE analysis, derived-state memory governance, temporal drift, and non-stationary robustness as evidence gates.

## Implementation gate

Before integrated experiments, fix task/data splits, specialist roles and model versions, routing definitions, objectives, fault and Byzantine threat models, memory semantics, workspace capacity, communication accounting, primary metrics, replication, acceptance criteria, and reproducibility artifacts. Later gates require causal ablations, hidden evaluators, resource matching, intervention-identifiable mechanisms, memory/skill provenance, active-subgraph safety, drift evaluation, and derived-state rollback.

## Status

No claim of consciousness, AGI, open-ended self-improvement, autonomous self-healing, universally optimal cognitive organization, or complete Holobiont validation is supported. The current falsifiable question is whether controlled modular change improves utility, retention and robustness under matched resources, causal intervention, drift, dependency and adversarial evaluation.
