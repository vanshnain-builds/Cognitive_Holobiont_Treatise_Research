## Findings

Recent MoE studies show that different routing structures can reach similar task scores in controlled settings. This means task performance does not uniquely identify the internal mechanism.

Recent representation-learning theory separates statistical identifiability from structural identifiability. Learned latent vectors should therefore be described with explicit equivalence classes and assumptions.

Recent agent-memory studies show that memory operations and reusable skills can be learned and refined outside the base model parameters. This supports bounded external-state adaptation, not an unrestricted claim of general improvement.

Recent online-learning work uses dynamic regret when the reference solution changes over time. Such a bound is a tracking result under explicit assumptions.

## Equations

For a mechanism m:

tau_m = E[Y | do(m=1)] - E[Y | do(m=0)].

For n equally correlated observations:

Var(mean) = sigma^2/n * [1 + (n-1)rho].

Thus n_eff = n / [1 + (n-1)rho] is only a diagnostic approximation.

For a moving comparator:

R_dyn(T) = sum_t f_t(x_t) - sum_t f_t(x*_t).

## Claim status

Established with scope: controlled routing equifinality; conditional representation identifiability; bounded external memory and skill improvements; dynamic-regret analysis under explicit assumptions.

Plausible synthesis: intervention-based attribution; lineage-aware state; covariance-aware evidence accounting; dynamic-regret plus retention evaluation.

Unsupported: routing topology uniquely determines cognition; skill growth implies open-ended capability; provenance alone proves truth; dynamic-regret improvement proves whole-system convergence.

Incomplete without assumptions: benchmark gain implies mechanism identification; replica count implies independent evidence; latent similarity implies semantic identity; dynamic-regret bounds imply general convergence.
